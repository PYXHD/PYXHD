<h3>What this project demonstrates:</h3>

<p style="padding-left: 32px">- Building and deploying a complete mobile application from scratch with React Native and Expo</p>
<p style="padding-left: 32px">- Developing and distributing Android applications through Google Play</p>
<p style="padding-left: 32px">- Authentication flows with email verification and password recovery</p>
<p style="padding-left: 32px">- Deep linking and authentication redirects between emails and the mobile application</p>
<p style="padding-left: 32px">- PKCE-based authentication and user session handling</p>
<p style="padding-left: 32px">- State management and persistent user data with Supabase</p>
<p style="padding-left: 32px">- Secure transactional email delivery with custom templates</p>
<p style="padding-left: 32px">- Interactive UI development with a dynamic 3D component</p>
<p style="padding-left: 32px">- Scalable component architecture and maintainable code organization</p>
<p style="padding-left: 32px">- Local Android production builds with Gradle and release signing</p>
<p style="padding-left: 32px">- Writing tested and maintainable code with Jest</p>
